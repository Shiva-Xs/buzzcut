Match required_if case-insensitively when argument ignores case

Arguments conditionally required by `required_if` now match case-insensitively when the target argument has `case_insensitive(true)`. Previously, casing differences like `"val"` vs `"Val"` accepted the argument via `possible_values()` but failed to trigger the required dependency.

- Parsing: `MatchedArg` stores case insensitivity from `ArgSettings::IgnoreCase` and compares values lowercased during conditional requirement checks
- Docs: document and illustrate case-insensitive requirement checks in `Arg` doc comments
- Tests: add pass and fail test cases for case-insensitive `required_if_eq` in `tests/require.rs`

Follow-up from https://github.com/clap-rs/clap/pull/2446 on the v2-master branch.

Not tested: `cargo test --test require`.
