Update Command description and help docblocks to string

Change `@var string|null` to `@var string` on `Command::$description` and `Command::$help`. Both properties are initialized in the constructor via `setDescription()` and `setHelp()`, and the nullable type caused Psalm to emit `NonInvariantDocblockPropertyType` on new commands (https://github.com/psalm/psalm-plugin-laravel/issues/144).

Not tested: Psalm static analysis on a subclass extending `Command`.
