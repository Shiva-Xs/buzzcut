Validate decorator dependencies is an array and throw descriptive error

Throw `FST_ERR_DEC_DEPENDENCY_INVALID_TYPE` when server decorator dependencies are not an array. Decorator resolution assumed an array and failed with misleading errors when other types were passed.

- Decorators: check `!Array.isArray(dependencies)` in `lib/decorate.js` and throw `FST_ERR_DEC_DEPENDENCY_INVALID_TYPE`
- Tests: add regression test in `test/decorator.test.js` and replace incorrect `t.ok` equality assertions with `t.same`

Tested: `npm run test` and `npm run benchmark`.
