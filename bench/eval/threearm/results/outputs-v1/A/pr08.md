Only enforce lazy loading prevention when hydrating multiple models

Only set `$model->preventsLazyLoading` in `Builder.php` when `count($items) > 1`. If only a single model is hydrated, N in N+1 is always 1, so lazy loading cannot cause an N+1 query issue. Added a test in `EloquentStrictLoadingTest.php`.

Not tested: `phpunit tests/Integration/Database/EloquentStrictLoadingTest.php`.
