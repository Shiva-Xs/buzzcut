Support custom messages and grouped patterns in no-restricted-imports

Allow `no-restricted-imports` `patterns` to accept objects with `group` glob arrays and custom `message` strings as specified in https://github.com/eslint/eslint/issues/11843.

- Rule schema: allow `patterns` to be an array of `{ group, message }` objects in `lib/rules/no-restricted-imports.js` while keeping string array support
- Error reporting: append `customMessage` when defined via `patternWithCustomMessage` message ID
- Docs: add documentation and configuration examples for pattern objects in `docs/rules/no-restricted-imports.md`
- Tests: add test cases for pattern groups with and without custom messages in `tests/lib/rules/no-restricted-imports.js`

Not tested: `npm test tests/lib/rules/no-restricted-imports.js`.
