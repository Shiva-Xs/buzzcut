Add transitional config options for JSON parsing and timeout errors

Add a `transitional` options config object with schema validation to ease migrations between package versions while keeping default behavior backward compatible. This allows opting into strict JSON error parsing (#61, #907, #2791) and specific `ETIMEDOUT` errors (#1543).

- Transitional options: introduce `silentJSONParsing` (default `true`), `forcedJSONParsing` (default `true`), and `clarifyTimeoutError` (default `false`) with schema assertions
- Request body: serialize primitive types to JSON when `Content-Type` is `application/json` (#2613) in `lib/defaults.js`
- Adapters: throw `ETIMEDOUT` on request timeout when `clarifyTimeoutError` is enabled, and use `onloadend` when available in `lib/adapters/xhr.js`
- Context binding: invoke transform functions with the request config as `this` context in `lib/core/transformData.js`
- Tests: add test coverage for transitional validators, strict JSON parsing errors, and timeout codes in `test/specs/`

Not tested: `npm test`.
