Inline HTML formatter template helpers into html.js

Inline HTML template helpers into `lib/cli-engine/formatters/html.js` and remove the separate `html-template-*.js` files. The `gensite` script in `Makefile.js` treats every `.js` file in `formatters/` as a standalone formatter to generate documentation, which broke after https://github.com/eslint/eslint/pull/14287 added non-formatter helper files there.

The entire 342-line diff is mechanical code movement with no behavior changes.

- Formatters: inline `pageTemplate`, `messageTemplate`, and `resultTemplate` directly into `html.js`
- Cleanup: delete `html-template-page.js`, `html-template-message.js`, and `html-template-result.js` from `lib/cli-engine/formatters/`

Not tested: `node Makefile.js gensite` and formatter tests (`npm test`).
