Cache sorted menus to prevent in-place mutation race condition

Sort menus on copies managed by a thread-safe cache in `navigation/` to prevent concurrency races from mutating `.Site.Menus` in place (#7594). This mirrors the existing sort and cache pattern used for Pages.

- Menu caching: introduce `menuCache` in `navigation/menu_cache.go` with mutex synchronization and menu equality checks
- Sorting: update `ByWeight`, `ByName`, and `Reverse` in `navigation/menu.go` to retrieve cloned and sorted copies via `smc.get()`
- Cache tests: add parallel concurrency tests in `navigation/menu_cache_test.go`
- Site tests: add `TestMenuSort` in `hugolib/menu_test.go` verifying consistent menu ordering across multiple template accesses

Not tested: `go test ./navigation ./hugolib`.
