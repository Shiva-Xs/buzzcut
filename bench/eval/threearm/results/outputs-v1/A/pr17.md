Speed up Ipv4Addr serialization using a decimal lookup table

Serialize `Ipv4Addr` using an internal lookup table instead of `Display` formatting, speeding up JSON serialization by ~4x in profiling.

- Formatting: write octets directly to a stack buffer using a decimal digits lookup table `DEC_DIGITS_LUT` in `serde/src/ser/impls.rs`
- Safety: remove `#![forbid(unsafe_code)]` in `serde/src/lib.rs` to allow `str::from_utf8_unchecked` on the ASCII buffer

Not tested: `cargo test -p serde --lib` and serialization benchmarks.
