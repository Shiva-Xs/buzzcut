Add type parameters to Callable annotations in decorator factories

Add type parameters to bare `Callable` return types in Flask decorator factories and preserve wrapped function signatures in `setupmethod()` (#4060).

- Decorator factories: annotate template filters, tests, globals, and error handlers with specific `Callable` type parameters in `app.py` and `scaffold.py`
- Setup methods: type `setupmethod()` with a generic `TypeVar` so wrapped methods retain their types
- Blueprints: pass `provide_automatic_options` explicitly in `Blueprint.add_url_rule()` to match the underlying signature
