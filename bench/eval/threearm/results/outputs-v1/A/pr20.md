Proxy Mocha exports to current context for ESM support with --parallel

Proxy exports like `describe` and `it` to `currentContext` in `lib/mocha.js` so that `import { describe, it } from 'mocha'` works with `--parallel` in ES modules (closes #4559).

- Core exports: wrap exported helpers (`describe`, `it`, hooks, `run`, `.only`, `.skip`) in forwarding functions that delegate to `currentContext`
- ESM parallel tests: verify named ESM imports function properly across worker threads in `test/integration/parallel.spec.js`
- CommonJS tests: verify all re-exported Mocha functions in `test/integration/common-js-require.spec.js`

Not tested: integration tests (`npm test` and `node test/integration/parallel.spec.js`).
