Add UseLongFormatForHelpSubcommand app setting

Add `AppSettings::UseLongFormatForHelpSubcommand` so the `help` subcommand prints long-form help messages instead of the default short form (closes https://github.com/clap-rs/clap/issues/2435).

- Settings: add `AppSettings::UseLongFormatForHelpSubcommand` flag in `src/build/app/settings.rs`
- Parser: pass `is_set(AS::UseLongFormatForHelpSubcommand)` into `parser.help_err()` in `src/parse/parser.rs`
- Tests: verify nested, top-level, and single-arg help output formatting in `tests/app_settings.rs`

Not tested: `cargo test --test app_settings`.
