Cache and copy menus on sort to prevent data races

Sorting `.Site.Menus` mutated the underlying slice in place, causing race conditions when accessed concurrently during site builds (#7594). Sorting now operates on menu copies backed by a cache, matching the logic used for Pages.

- Menu cache: adds thread-safe `menuCache` in `navigation/` to cache sorted and reversed menu slices
- Sort methods: updates `ByWeight`, `ByName`, and `Reverse` to retrieve cached copies rather than sorting in place
- Tests: adds concurrent cache stress tests across 100 goroutines and template tests asserting sort stability

Not tested: Run `go test ./navigation... ./hugolib...`.
