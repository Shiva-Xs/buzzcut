Only prevent lazy loading when hydrating more than one model

Only set `preventsLazyLoading` when hydrating more than one model (`count($items) > 1`) in `src/Illuminate/Database/Eloquent/Builder.php`. When hydrating only a single model, `N` in `N+1` is always 1, so lazy loading is not an N+1 problem.

Not tested: Run `tests/Integration/Database/EloquentStrictLoadingTest.php`.
