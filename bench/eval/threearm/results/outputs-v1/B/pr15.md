Truncate large diff strings in base reporter

Generating diffs with jsdiff for large assertion strings can synchronously block for several minutes (#3675). Truncate `actual` and `expected` strings before diff generation.

- Reporter truncation: caps `actual` and `expected` strings at `diffSize = 2048` characters and appends `' ... Lines skipped'`
- Tests: verifies that long `actual` and `expected` diff inputs are truncated

Not tested: Run `test/reporters/base.spec.js`.
