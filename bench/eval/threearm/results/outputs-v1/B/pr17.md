Speed up Ipv4Addr serialization with decimal lookup table

Profiling showed serializing `Ipv4Addr` is disproportionately slow due to `std::fmt::Display` dispatch. This replaces `serialize_display_bounded_length!` with direct integer formatting using a decimal lookup table, running ~4x faster.

- Serialization: uses `DEC_DIGITS_LUT` and `format_u8` to write octets into a fixed buffer
- Crate attributes: removes `#![forbid(unsafe_code)]` in `lib.rs` to construct the string with `str::from_utf8_unchecked`

Not tested: Run `cargo test` and benchmark `Ipv4Addr` serialization.
