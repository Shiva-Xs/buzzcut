Validate decorator dependencies are an array

Throw a clear error when a server decorator dependency is specified as a non-array, preventing misleading errors when array methods are called.

- Decorator validation: `decorate()` throws `FST_ERR_DEC_DEPENDENCY_INVALID_TYPE` if `dependencies` is not an array
- Tests: adds coverage for invalid dependency types and replaces `t.ok` with `t.same` for equality assertions

Tested: `npm run test` and `npm run benchmark`.
