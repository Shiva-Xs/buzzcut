Update Command description and help docblocks to string

`Command::$description` and `Command::$help` are never null because they are set via `Command::setDescription()` and `Command::setHelp()` in the constructor. The `@var string|null` docblock caused Psalm to emit a `NonInvariantDocblockPropertyType` error for newly created commands (https://github.com/psalm/psalm-plugin-laravel/issues/144).

Not tested: Psalm static analysis on newly created commands.
