Support case-insensitive matching in required_if conditions

When an argument uses `.case_insensitive(true)`, options conditionally required by `.required_if_eq` previously only matched exact-case values, failing to require arguments when casing differed. Conditionally required argument checks now respect case insensitivity.

- `MatchedArg`: records `case_insensitive` and compares values lowercased when enabled
- `ArgMatcher::inc_occurrence_of`: accepts the `ArgSettings::IgnoreCase` flag from the parser
- `tests/require.rs`: adds tests for case-insensitive `required_if_eq` validation

Follow-up to https://github.com/clap-rs/clap/pull/2446 from the v2-master branch.

Not tested: Run `cargo test --test require`.
