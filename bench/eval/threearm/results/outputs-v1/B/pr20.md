Proxy Mocha exports to current context for ESM parallel runs

`import { describe, it } from 'mocha'` fails when running ES modules under `--parallel` because exports statically captured the initial context (#4559).

- Interface exports: proxies test functions, hooks, and `.only`/`.skip` modifiers through `currentContext` so calls dispatch to the active context
- CommonJS tests: adds integration tests running a fixture exercising all Mocha exports with `--delay`
- Parallel ESM tests: adds tests verifying `--parallel --jobs 2` when importing `describe` and `it` directly from `mocha`

Not tested: Run `npm test` across supported Node versions.
