Inline HTML formatter templates into html.js

During release, the `gensite` script failed because it loads every `.js` file in `lib/cli-engine/formatters/` as a formatter to generate the docs site. The helper files added in https://github.com/eslint/eslint/pull/14287 broke this because they are not formatters.

### What's mechanical
- Inlines `pageTemplate`, `messageTemplate`, and `resultTemplate` into `html.js` and deletes the three helper files (all ~340 lines of the diff).

### Behavior changes
- None: formatting behavior is unchanged, ensuring only valid formatters reside in `formatters/`.

Not tested: Run `Makefile.js gensite` and check HTML formatter output.
