Add AppSettings::UseLongFormatForHelpSubcommand

Add `AppSettings::UseLongFormatForHelpSubcommand` so the `help` subcommand can print long-format help instead of short form (https://github.com/clap-rs/clap/issues/2435).

- Setting: adds `UseLongFormatForHelpSubcommand` to `AppSettings` (flag `1 << 43`), string-parsable from `"uselongformatforhelpsubcommand"`
- Parser: checks the setting on `self.app` to pass the boolean flag into `help_err()`
- Tests: verifies long-form help formatting on direct subcommands, nested subcommands, and single-arg apps

Not tested: Run `cargo test --test app_settings`.
