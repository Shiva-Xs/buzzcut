Allow custom error messages for pattern groups in no-restricted-imports

`no-restricted-imports` previously prohibited custom error messages for restricted patterns. Per https://github.com/eslint/eslint/issues/11843, patterns can now be grouped into objects specifying a `group` of patterns and a custom `message`.

- Rule schema: accepts objects with `group` string array and optional `message` string in `patterns`
- Error reporting: emits `patternWithCustomMessage` appending the custom message when a grouped pattern matches
- Tests and docs: documents group config in the rule doc and adds test cases for custom pattern errors

Not tested: Run unit tests for `no-restricted-imports`.
