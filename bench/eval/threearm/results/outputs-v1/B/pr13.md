Parameterize Callable types in decorator factories

Add type parameters to `Callable` return types on decorator factories so decorated functions retain type information (#4060).

- `setupmethod`: uses `TypeVar` `F` bound to `Callable` so wrapped methods preserve their signatures
- Decorator factories: `template_filter`, `template_test`, `template_global`, and error handlers specify concrete `Callable` signatures
- `Blueprint.add_url_rule`: forwards `provide_automatic_options` in the recorded callback

Tested: `pre-commit`, `pytest`, and `tox` (no tests failed).
