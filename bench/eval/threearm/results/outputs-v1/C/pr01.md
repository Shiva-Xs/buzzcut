Add build ID to Karma Sauce Labs configuration to fix README badge

This change updates `karma.conf.js` to include the build ID (`github-${env.GITHUB_RUN_ID}_${env.GITHUB_RUN_NUMBER}`) in the Sauce Labs configuration (`sauceConfig.build`) and bundle directory path. It also updates browser capability properties to `platformName`, `browserVersion`, and adds `'sauce:options': sauceLabs`.

Passing build IDs to the tests fixes the invalid status badge on the README, which currently shows `unknown` because no new builds have been created for a while. Displaying an up-to-date build status promotes MochaJS as a stable testing framework.
