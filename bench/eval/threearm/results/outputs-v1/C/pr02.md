Fix property docblock types for Command::$description and Command::$help

Update the docblock type annotations for `Command::$description` and `Command::$help` in `src/Illuminate/Console/Command.php` from `@var string|null` to `@var string`.

`Command::$description` and `Command::$help` are never null because they are set to non-null values in the constructor via `Command::setDescription()` and `Command::setHelp()`, respectively. The incorrect type annotation for `Command::$description` causes Psalm to emit a `NonInvariantDocblockPropertyType` error for newly created commands (see https://github.com/psalm/psalm-plugin-laravel/issues/144).
