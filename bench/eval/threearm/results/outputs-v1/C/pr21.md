Inline HTML formatter templates into html.js

Consolidates `html-template-page.js`, `html-template-message.js`, and `html-template-result.js` into `lib/cli-engine/formatters/html.js` and removes the separate template files.

During the release process, the `gensite` script in `Makefile.js` scans `./lib/cli-engine/formatters/` and assumes every `.js` file is an ESLint formatter to generate documentation at https://eslint.org/docs/user-guide/formatters/. After https://github.com/eslint/eslint/pull/14287, the template helper files in that directory caused failures because they are not standalone formatters. Merging them back into `html.js` fixes the release build.
