Remove redundant bool from ParseResult::FlagSubCommandShort

Removes the boolean field from `ParseResult::FlagSubCommandShort`, simplifying the variant to `FlagSubCommandShort(String)`.

The `bool` field is no longer required because parsing state is already fully encoded in `Parser`'s `flag_subcmd_at` field. Checking `self.flag_subcmd_at` directly also eliminates an unnecessary `.unwrap()` / `.expect()`.
