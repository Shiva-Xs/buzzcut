Use Duration.Truncate in logger latency formatting

Replaces manual duration truncation (`param.Latency - param.Latency%time.Second`) with `param.Latency.Truncate(time.Second)` in `logger.go`.

`Duration.Truncate` was added in Go 1.9, and Gin now requires Go version 1.13+, so the legacy truncation workaround for Go < 1.8 is no longer needed.
