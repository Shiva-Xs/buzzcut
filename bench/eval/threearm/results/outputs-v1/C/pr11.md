Support case-insensitive matching for conditionally required arguments

Makes conditional requirement checks (`required_if_eq`, `required_if_eq_any`, `required_if_eq_all`) case-insensitive when the dependent argument has `case_insensitive(true)` enabled.

Previously, if an argument was configured with `.possible_values()` and `.case_insensitive(true)`, other options conditionally required via `.required_if("Arg", "Val")` were only triggered if "Arg" matched "Val" with exact case. If a user provided "val", the argument was accepted but the conditionally required option was not enforced.

This change records the case-insensitivity setting in `MatchedArg`, performs lowercased string comparisons when evaluating requirement checks, updates documentation, and adds test cases in `tests/require.rs`.

This is a follow-up to https://github.com/clap-rs/clap/pull/2446, which proposed similar changes on the `v2-master` branch.
