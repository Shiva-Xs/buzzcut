Support custom messages for pattern groups in no-restricted-imports

Updates the `no-restricted-imports` rule to allow `patterns` to be defined as objects containing `group` (an array of pattern strings) and an optional custom `message`, alongside the existing array-of-strings format.

As specified in https://github.com/eslint/eslint/issues/11843, this allows patterns to be grouped together with custom error messages that are appended when an import matches a restricted pattern (e.g. `{ patterns: [{ group: ["foo/*", "bar/*"], message: "'foo' and 'bar' are deprecated, please use 'baz' instead." }] }`). Updates the rule logic, schema, documentation in `docs/rules/no-restricted-imports.md`, and test cases in `tests/lib/rules/no-restricted-imports.js`.
