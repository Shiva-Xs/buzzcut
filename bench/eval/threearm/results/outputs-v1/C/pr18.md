Add AppSettings::UseLongFormatForHelpSubcommand

Adds `AppSettings::UseLongFormatForHelpSubcommand`, allowing the `help` subcommand to print the long-form help message instead of the default short form.

In `src/parse/parser.rs`, this checks whether `AppSettings::UseLongFormatForHelpSubcommand` is enabled and passes the boolean flag to `parser.help_err()`. Includes documentation, changelog update, and tests for global and subcommand usage.

Closes https://github.com/clap-rs/clap/issues/2435.
