Add transitional options for JSON parsing, timeout errors, and options validation

Introduces the `transitional` configuration namespace to support opt-in behavior changes and ease future migration between Axios versions:
- `silentJSONParsing` (default: `true`): When set to `false` and `responseType` is `'json'`, throws a `SyntaxError` on malformed JSON responses rather than silently ignoring errors (#61).
- `forcedJSONParsing` (default: `true`): Controls automatic JSON parsing of string responses when `responseType` is not explicitly `'json'` (#2791, #907).
- `clarifyTimeoutError` (default: `false`): Emits `ETIMEDOUT` error code instead of `ECONNABORTED` on request timeouts (#1543).

Additional changes:
- Converts primitive types to JSON during request transformation if `Content-Type` is `application/json` (#2613).
- Invokes transformers in the context (`this`) of the config object.
- Implements options schema validation and automated deprecation warning helper in `lib/helpers/validator.js`.
- Updates `lib/adapters/xhr.js` to use `onloadend` when supported with fallback to `onreadystatechange`, resolving timeout and error handling issues.
- Adds TypeScript definitions (`TransitionalOptions`) and documentation in `README.md`.
- Reference: tested as `axios-lab` fork (CodeSandbox: https://codesandbox.io/s/axios-lab-test-2q53x?file=/src/index.js).
