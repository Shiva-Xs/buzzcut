Redirect stderr to /dev/null for pacmd help in completions

Redirects stderr to `/dev/null` (`pacmd help 2>/dev/null`) in `share/completions/pacmd.fish` and `share/completions/pactl.fish`.

When PulseAudio is not running or not running as a session daemon, `pacmd help` outputs:
```
No PulseAudio daemon running, or not running as session daemon.
```
to stderr, which ends up printed directly to the user's terminal. Redirecting stderr suppresses this output.

Reviewer consideration: Should a fallback be added for when `pacmd` is available but `pacmd help` fails? The completions still seem to work.
