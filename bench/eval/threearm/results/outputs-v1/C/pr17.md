Optimize Ipv4Addr serialization

Optimizes `Ipv4Addr` serialization by replacing `serialize_display_bounded_length!` with a lookup-table decimal formatting helper (`format_u8` and `DEC_DIGITS_LUT`) in `serde/src/ser/impls.rs`. Also removes `#![forbid(unsafe_code)]` in `serde/src/lib.rs` to allow calling `str::from_utf8_unchecked` on the ASCII byte buffer.

Profiling revealed that serializing `Ipv4Addr` to JSON was disproportionately slow. Standard library formatting through `std::fmt::Display` involves substantial dynamic dispatch overhead. Using this integer formatting algorithm makes serialization ~4x faster. Going through `itoa`'s public interface was not faster because LLVM keeps the `itoa::Buffer` in memory.
