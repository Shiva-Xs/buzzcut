Throw error when decorator dependencies are not an array

Defines and throws a new `FST_ERR_DEC_DEPENDENCY_INVALID_TYPE` error in `lib/decorate.js` if a decorator's dependencies argument is not an array.

Previously, decorator dependency handling assumed an array and failed with misleading errors when another type was supplied. This also fixes several assertions in `test/decorator.test.js` where `t.ok` was mistakenly used instead of `t.same` for equality checks, and adds a test covering invalid dependency types.

Testing:
- Ran `npm run test` and `npm run benchmark`.
