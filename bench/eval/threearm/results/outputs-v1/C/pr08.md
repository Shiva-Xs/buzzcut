Only prevent lazy loading when hydrating multiple models

Updates `src/Illuminate/Database/Eloquent/Builder.php` so that `$model->preventsLazyLoading` is only enabled when hydrating more than one model (`count($items) > 1`). Adds integration tests in `tests/Integration/Database/EloquentStrictLoadingTest.php`.

With this change, strict mode only throws an exception if the models being hydrated are more than 1. If there is only a single model, `N` in `N+1` will always be 1, so lazy loading is not an issue.
