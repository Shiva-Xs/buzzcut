Proxy Mocha exports to current context for ESM parallel support

Updates `lib/mocha.js` to proxy top-level exports (`describe`, `it`, hooks, and helpers) to `currentContext` rather than binding them statically at module load time.

When using ES modules with `--parallel`, `import { describe, it } from 'mocha'` failed because the test runner creates separate contexts across executions. Proxying each export to `currentContext` allows named imports to target the active context. Adds integration tests for CommonJS requiring of exports and ES module execution with `--parallel`.

Closes #4559.
