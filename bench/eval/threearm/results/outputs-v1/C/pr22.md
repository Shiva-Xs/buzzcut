Prevent race conditions when sorting menus by caching sorted copies

Introduces `menuCache` in `navigation/menu_cache.go` and updates `navigation/menu.go` so that menu sorting methods (`ByWeight`, `ByName`, and `Reverse`) operate on copied `Menu` slices retrieved through the cache rather than mutating the original slice in place.

Currently, `.Site.Menus` is mutated when sorted, leading to race conditions and concurrency issues (#7594). Pages already uses this sort and cache pattern; this change applies the identical design to menus. Adds concurrent tests for `menuCache` and site-level menu sorting tests in `hugolib/menu_test.go`.

Closes #7594.
