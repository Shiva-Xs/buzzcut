Improve type annotations for decorator factories and setupmethod

Adds specific type parameters to `Callable` return signatures across decorator factories (`template_filter`, `template_test`, `template_global` on both `app` and `blueprints`, and error handlers in `scaffold`).

To avoid stripping type information from wrapped functions, `setupmethod()` in `src/flask/scaffold.py` now uses a generic `TypeVar` `F` bound to `Callable`. Updating `setupmethod()` surfaced signature inconsistencies in `add_url_rule()`, where `provide_automatic_options` has been added. Also updates `CHANGES.rst`.

Fixes #4060.
