Truncate large actual and expected strings in diff reporter

Truncates `actual` and `expected` strings to 2048 characters (appending `' ... Lines skipped'`) before passing them to `jsdiff` in `lib/reporters/base.js`. Also adds test coverage in `test/reporters/base.spec.js`.

Mocha generates diffs on assertion errors by stringifying `err.actual` and `err.expected` and running them through `jsdiff`. For large strings, this synchronous calculation can block execution for several minutes due to known `jsdiff` performance issues. Limiting string size (similar to Node's `assert`) avoids freezing test runs. An alternative diff library may still be evaluated in the medium term.

Closes #3675.
