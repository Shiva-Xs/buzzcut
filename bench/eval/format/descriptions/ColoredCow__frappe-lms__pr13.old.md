fix: clear the quiz answer selection when moving to the next question

Fixes #287: after Check → Next in a quiz, the next question still showed the previous answer selected, because `resetQuestion()` reset `selectedOptions` to `[0,0,0,0]` but the radio and checkbox inputs had no `:checked` binding for Vue to update. Both inputs in `Quiz.vue` now bind `:checked="selectedOptions[index - 1] === 1"`. That fix is 2 lines; the rest of the diff is upstream's demo-data work (frappe/lms#2159) that the branch carries: a demo course "A guide to Frappe Learning" created after the setup wizard, a Clear Demo Data menu item, and `frappe/payments` as a required app. Not tested: answer Q1 of a multi-question quiz, Check → Next, and check Q2 starts empty, for single- and multiple-answer questions.
