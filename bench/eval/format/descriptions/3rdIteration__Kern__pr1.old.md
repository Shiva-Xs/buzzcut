Add CrowPanel 10.1" support, per-board CI firmware and a web flasher

Adds the Elecrow CrowPanel Advanced 10.1" ESP32-P4 as a fourth board, `crowpanel_101` (1024x600 MIPI DSI panel on EK79007, GT911 touch, and the second 3.3 V LDO channel the panel needs), and makes CI build all four boards in a matrix and upload each one's flashable files as a `firmware-<board>` artifact. On pushes to `master` a new `deploy-flasher` job publishes `flasher/index.html`, an esptool-js 0.6.0 web flasher for Chrome and Edge, with those builds to GitHub Pages; Pages must be set to GitHub Actions in the repo settings. `actions/download-artifact` is pinned to v4.1.3 for the arbitrary file write in >= 4.0.0, < 4.1.3, `test-each-commit` marks the workspace a safe directory, and the README covers the board, the flasher and flashing CI builds, which it warns not to use as a signer for real funds. Not tested: the four builds and a flash on the board.
