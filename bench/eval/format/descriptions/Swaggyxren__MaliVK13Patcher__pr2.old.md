Fix APK install on Android 16, add launcher icon, Linux build, new UIs

A user reported the v1.0.0 APK won't install on Android 16 and has no launcher icon; the adaptive icon used `@android:color/...` as drawables, which newer resource parsers reject, the most likely cause, and the SDK was 34. The icon now uses real vector drawables (background `#0E0E10`, a white "V", a monochrome layer for themed icons), `compileSdk` and `targetSdk` go to 35, the version to 1.0.1 (code 2), and the debug keystore signs with v1+v2+v3. The branch also rewrites the APK and Windows UIs with dark and light themes and pack options (`PackOptions` in `core/patcher.py`, defaults unchanged at lz4hc level 9), adds a PyInstaller Linux build and CI job, and fixes CI's path and APK name checks. It supersedes #1. Not tested: install on an Android 16 device and patch a real `vendor.img`.
