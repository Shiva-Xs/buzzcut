Harden the GoHighLevel OAuth flow and token selection

Subaccount sync failed with "no agency/company token" when a newly connected location wasn't mirrored into `locations` yet, and the OAuth callback accepted a missing state. The Company token lookup now falls back from the agency mapping to the company of any OAuth row for that location, then to the newest Company token on file (a single-agency assumption). The callback redirects to `/settings/integrations?ghl=error&reason=invalid_oauth_state` on a missing or mismatched state, `/oauth/gohighlevel/start` requires a `client_id` and sends the new `GHL_OAUTH_SCOPE`, the frontend's Connect links go through that endpoint instead of a hard-coded install URL, the code exchange tries both Company and Location user types, token lookup refreshes tokens expiring within 60 s, and message sends try API versions 2023-02-21, 2021-07-28 and 2021-04-15. `npm run check` and `npm run build` pass for `@agentflow/api`.
