Add a design doc for automated booking and WhatsApp messaging

The repo has only a README, so this adds a planning document for automated booking and WhatsApp messaging, `docs/automated-booking-whatsapp-deep-dive.md`, linked from the README; no code changes. It proposes explicit booking states with an event log and 5 to 15 minute slot holds, treats WhatsApp as one delivery channel (Twilio for the fastest MVP with SMS fallback, Meta's Cloud API for cost and template control), designs around the 24-hour service window, approved templates and `X-Hub-Signature-256` webhook checks, and lays out the data model, automation jobs, security, five milestones and the open decisions. A local Python check confirmed the Markdown files exist and end with a newline; the repo has no test suite.
