Add a continuous benchmarking tutorial for current-bench

This adds a platform tutorial, `data/tutorials/platform/2_13_current_bench.md` at `/docs/continuous-benchmarking`, on benchmarking OCaml projects with current-bench at bench.ci.dev: the `make bench` contract (JSON on stdout, logs on stderr), the JSON format, the cobench library, setting up the GitHub App with an optional `bench.Dockerfile`, the dashboard and PR workflow, self-hosting with Docker Compose, and submitting results through the API. It links to the OCaml-CI and Docker tutorials, lists `bootstrapping-a-dune-project` as a prerequisite, and opens with a note that it was written with AI assistance and reviewed by the OCaml.org team. Not tested: `dune build`, the rendered page, its links, and the code examples still need a check.
