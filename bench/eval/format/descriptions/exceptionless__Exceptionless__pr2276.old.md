Return 426 for premium search filters and fix Svelte upgrade prompts

The Svelte UI checked stack searches against the event field rules and only read the raw URL filter, so free stack searches like `critical:true` got an upgrade prompt, premium filters from saved views got none, and direct API calls with a premium filter got silently filtered results. Event search, event count and stack search now return `426 Upgrade Required` for a premium filter on a non-premium organization (policy centralized in `ApiFilterPolicy`, global admins still exempt for scoped searches, stack-mode queries validated by a new `EventStackQueryValidator`), and the Svelte premium check is per resource and reads the effective filter, saved views included. The OpenAPI document gains the 426 responses and the Angular error text falls back to `response.data.title`; no configuration key or WebSocket message changes. `npm run validate`, `npm run test:unit` (310 passed), `npm run build` and three controller regression tests pass, and in local dogfooding stack `title:timeout` and event `tags:important` prompted an upgrade while stack `critical:true` and event `reference:ABC123` didn't.
